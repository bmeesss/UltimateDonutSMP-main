## Console acceptance greps

Run after the full matrix. **Every one of these must print nothing.**

```bash
LOG=plugins/UltimateDonutSmp/../../logs/latest.log   # adjust to your log path

grep -n "ExceptionInInitializerError"                       "$LOG"   # bug #1
grep -n "No constructor with"                               "$LOG"   # bug #1
grep -n "NoClassDefFoundError: .*WrappedEnumEntityUseAction" "$LOG"  # bug #1
grep -n "NoSuchMethodError"                                 "$LOG"   # bug #5
grep -n "setOwningPlayer"                                   "$LOG"   # bug #5
grep -n "Could not pass event"                              "$LOG"   # phase 9
grep -n "EventException"                                    "$LOG"   # phase 9
grep -n "IllegalArgumentException"                          "$LOG"   # scoreboard 32/16 limits
grep -n "\[SQLITE\]\|database is locked"                    "$LOG"   # phase 8
grep -n "N values for M columns"                            "$LOG"   # phase 8 savePlayer
```

Expected present (once, informational — not an error):

* `[Tablist] Unable to send Adventure tablist name components …` — **only** if the NMS route still
  fails on your Spigot build. It is acceptable (the name-preserving fallback covers it) but note it
  in the matrix.

## Pass criteria

* No `ExceptionInInitializerError` / `No constructor with [EnumHand]` anywhere in the log.
* Player names visible in the tab list on both clients.
* Rows 18, 29, 30, 31 all PASS on **both** clients (the four originally reported bugs).
* Row 35 shows no accidental `STONE`.
* Rows 58–60 PASS (persistence beyond money).
* Every remaining failure is recorded with the exact console error, not marked PASS by omission.
